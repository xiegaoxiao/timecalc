## 3. 发布演练记录（checklists §10）

1. `flutter build windows --release` → `build\windows\x64\runner\Release\timecalc.exe`（版本元数据已核验：FileDescription/ProductName「TimeCalc 时间计算器」）。
2. `tool/create_signing_cert.ps1` → 自签名代码签名证书（`build/signing/TimeCalcTestSigningCert.pfx`，build/ 已 gitignore，证书不入库）。
3. `CERT_PASSWORD=... tool/release.sh`：
   - `signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256` → **Successfully signed**；时间戳证书链校验通过；
   - `signtool verify /pa /v` → 时间戳链验证通过，根证书不受信任为预期（自签名非受信 CA，对应 SmartScreen 可能提示）；
   - 发布目录 `build/release/timecalc-v1.0.0-windows-x64/`（exe + dlls + data + LICENSE + CHANGELOG + README + SIGNING-NOTE）；
   - zip 打包（PowerShell Compress-Archive）→ `sha256sum -c SHA256SUMS` 全部 OK。
4. 冒烟：启动 `timecalc.exe` 进程稳定运行后退出，无启动异常。

已知限制（写入 CHANGELOG）：自签名非受信 CA（SmartScreen 可能提示）；100/125/150/200% DPI 未逐档实测（manifest 已声明 PerMonitorV2）；无安装器（便携 zip，按 M4 决策）。
