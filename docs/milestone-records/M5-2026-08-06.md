## 5. 数据模型与迁移

Milestone（PRD §9）：`goalId, title, date, status(todo/done), sortOrder`，加 id/createdAt/updatedAt 惯例字段；`date` 为 `yyyy-MM-dd` 本地日历日期文本（沿用 PRD §9 日期约定）。

迁移 v6→v7（`lib/core/database/database.dart`）：

```dart
from6To7: (m, schema) async {
  // v6 -> v7：新增里程碑表（FR-2 目标下的阶段性节点）。
  // createTable 自带 IF NOT EXISTS，重复升级/半迁移安全。
  await m.createTable(schema.milestones);
},
```

- 全新安装：`onCreate: m.createAll()` 自动建全部表；
- 升级安装：`stepByStep` 增量建表；
- 幂等回归测试覆盖「表已手工创建但 user_version 落后」场景（仿既有 addColumnIfMissing 的半迁移回归）。
