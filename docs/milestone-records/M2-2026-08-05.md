## 4. 数据与可靠性（checklists §4/§5）

- schema v2 迁移：升级成功保留数据、升级失败后原 v1 数据可用且可重试（`SchemaVerifier` 测试）。
- 批量延期、defer 原日期记录、update 改期记录均事务化；`deferMany` 中途失败整体回滚测试通过（NFR-2）。
- 日期按本地日历日期（yyyy-MM-dd 文本）存储，时间戳 UTC（沿用 v1 原则）。
- 统计由查询/纯 Dart 计算产生，无重复计数状态对象。
