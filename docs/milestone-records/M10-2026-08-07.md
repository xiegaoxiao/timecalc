# M10 里程碑验收记录（2026-08-07）：明暗主题切换

## 1. 交付内容

- **明暗主题三选一（M10）**：外观页由占位页重写为可配置——「跟随系统 / 浅色 / 深色」（Material `SegmentedButton`，每项带图标）；跟随系统时随 Windows 明暗自动切换，浅色/深色强制指定；**点击即生效**（写库 + `settingsProvider` 失效 → `TimeCalcApp` 整树换肤），无需单独保存/重启。
- **应用层**：`TimeCalcApp` 由写死 `ThemeMode.system`（注释「M3 起改为可由用户在设置中选择」一直未落地）改为 watch `settings.themeMode`；`_themeModeFrom` 把文本映射到 `ThemeMode`（取值与 `ThemeMode.name` 一致，未知值回退跟随系统）。`AppTheme.light()/dark()` 复用既有实现（含 contrast_test 固化对比度）。
- **外观页 UI**：分段按钮（点击即生效，无独立保存按钮；写库失败还原选择）+ 「当前模式」预览卡（并排展示浅色/深色色板的表面/主色色块对比，高亮当前选择）+ 切换反馈 SnackBar。
- **设置页摘要**：外观菜单项 subtitle 由「主题切换（后续里程碑提供）」改为实时摘要（跟随系统/浅色/深色）。
- **数据层（schema v12）**：Settings 新增 `theme_mode` 列（默认 `system`）；`from11To12` 用 `addColumnIfMissing` 幂等加列；drift 快照 v12 + migration 测试（v11→v12 / v1→v12 / 半迁移幂等）。

## 3. 数据模型与迁移

Settings（schema v12 新增 1 列，带默认值）：

```dart
TextColumn get themeMode => text().withDefault(const Constant('system'))();
```

迁移 v11→v12（`lib/core/database/database.dart`）：`from11To12` 用 `addColumnIfMissing` 幂等加列（沿用 v5→v6 / v8→v9 / v10→v11 同模式）。

- 全新安装：`onCreate: m.createAll()` 自动建列；
- 升级安装：`stepByStep` 增量补列；
- 幂等回归测试覆盖「列已手工补上但 user_version 落后」场景。

**覆盖恢复保留**：`_overwriteRestore` 暂存/回填清单新增 themeMode（与 close_behavior/自动备份/同步同模式，FR-9.5）。

## 4. 调度与换肤语义

- `TimeCalcApp._themeModeFrom`：文本 → `ThemeMode`，未知值回退 `ThemeMode.system`（对异常库值宽容）。
- 换肤链路：外观页点击分段 → 即时更新选中态（预览卡 + 整树换肤）→ `updateThemeMode` 写库 → `ref.invalidate(settingsProvider)` → `TimeCalcApp.build` 重新 watch → `MaterialApp.themeMode` 变化；写库失败还原选择并提示（runDbAction 已弹「数据保存失败」对话框）。
