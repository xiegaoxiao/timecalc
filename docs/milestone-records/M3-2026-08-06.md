## 3. 备份恢复演练记录（checklists §10）

自动化演练（backup_service_test.dart「导出 → 修改数据 → 覆盖恢复 → 数据一致」）：

1. 造基础数据（目标/科目/任务，含已完成任务）→ `exportBackup` 导出 zip。
2. 删除目标（连带任务）模拟数据变化。
3. `restoreBackup(overwrite)`：自动创建安全副本（断言文件存在）→ 单事务清空并写入备份数据。
4. 校验：目标与任务恢复一致（标题/状态/预估时长逐字段比对）。

损坏/版本不匹配演练：构造版本 999 的 manifest 与损坏 zip → 恢复被拒且原库数据保持可用（NFR-2）。

Windows 手动冒烟：`flutter build windows --debug` 成功；启动 `timecalc.exe` 进程稳定运行，Dart VM 服务正常，桌面控制器（窗口恢复/托盘注册）初始化无异常后手动退出。
