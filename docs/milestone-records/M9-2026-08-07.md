# M9 里程碑验收记录（2026-08-07）：WebDAV 整库文件同步（云同步落地）

## 1. 交付内容

- **整库文件同步（M9）**：以「整库快照」为同步单元（复用 `BackupService.exportBackup`/`restoreBackup(overwrite)` 全链路），把全部业务数据（目标/科目/里程碑/任务/检查项/重复模板/计划偏好）同步到 WebDAV，多台设备共用同一份数据。远端目录 `webdav_sync/` 与自动备份目录 `webdav_auto/` 隔离，只保留一份最新快照 `timecalc-sync.latest.timecalc` + 元数据 `timecalc-sync.meta.json`（`{format, version, seq, syncedAtUtc, appSchemaVersion}`，免下载大文件比较新旧）。
- **触发时机（四类 + 周期复查）**：启动拉取；业务表变更防抖 3s 推送；退出推送（5s 超时尽力而为，不阻塞退出）；设置页「立即同步」；运行中每 5 分钟周期复查远端。
- **拉取守卫**：远端快照由更高 schema 版本生成时中止并提示升级；拉取覆盖本地前自动安全副本（复用 FR-9.3）；运行时配置（close_behavior / 自动备份 / 同步自身）各设备独立保留（backup_codec + `_overwriteRestore` 保留分支）。
- **变更监听**：drift 无公开全局更新流（内部 StreamQueryStore 为 @internal），用 6 张业务表 `managers.<table>.watch()` 合并 + 防抖；**不监听 settings 表**（同步服务推送后写 seq/时间会触发回环，计划偏好由启动/周期/手动/退出推送覆盖）。
- **UI**：设置页新增「同步」菜单项；`/settings/sync` 独立页（启用开关 + WebDAV 账号表单（与自动备份共享账号，密码经 `flutter_secure_storage` DPAPI，NFR-3）+ 立即同步 + 最近同步时间 + 后写者胜语义说明）。

## 3. 数据模型与迁移

Settings（schema v11 新增 3 列，全部可空或带默认值）：

```dart
BoolColumn get webdavSyncEnabled => boolean().withDefault(const Constant(false))();
IntColumn get lastPushedSeq => integer().nullable()();
DateTimeColumn get lastSyncedAt => dateTime().nullable()();
```

迁移 v10→v11（`lib/core/database/database.dart`）：`from10To11` 逐列 `addColumnIfMissing`（幂等，防半迁移重复），与 v5→v6 / v8→v9 同模式。

- 全新安装：`onCreate: m.createAll()` 自动建全部列；
- 升级安装：`stepByStep` 增量补列；
- 幂等回归测试覆盖「列已手工补上但 user_version 落后」场景。

**覆盖恢复保留运行时配置**：`_overwriteRestore` 的暂存/回填清单新增 3 个同步列（与 close_behavior/自动备份同模式，FR-9.5）。

## 4. 同步语义与调度

- `WebDavSyncService`：未启用/未配置 WebDAV 账号 → 跳过（≠ 失败）；远端 meta 不存在 → seq 视为 0 只推送；远端 seq > 本地 → 拉取覆盖（安全副本 + 运行时保留 + seq 吸收），随后始终推送（nextSeq = max(local, remote) + 1）。
- 互斥：`_running` 同一时刻只允许一个同步在跑（周期/变更/手动并发时跳过）；`_restoring` 防止恢复写入触发变更推送回环。
- 触发接线：main.dart 启动 `syncOnce()` + `Timer.periodic(5min)` + `DatabaseChangeWatcher`（防抖 3s 调 `pushIfNeeded`）；DesktopController `_quitApp`（onWindowClose exit 分支 + 托盘退出）统一退出推送（5s timeout）。

## 9. 遗留事项

- 整库文件同步 = 后写者胜：两台设备同时编辑时最后推送者整体覆盖（每次拉取覆盖前自动安全副本，极端场景可恢复）；同步页已明示语义。
- WebDAV 服务器行为差异沿用 M8 的宽容处理（MKCOL/PROPFIND 409 重试等），未覆盖完整 RFC 4918 语义（重定向跳转、分块上传大文件）。
- 计划偏好变更不触发「变更推送」（settings 表不监听防回环），由启动/周期/手动/退出推送覆盖（≤5 分钟），可接受。
