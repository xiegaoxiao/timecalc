# M6 里程碑验收记录（2026-08-06）：任务检查项 FR-4.1

## 1. 交付内容

- **检查项数据层（schema v8）**：新增 ChecklistItems 表（`taskId`/`title`/`done`/`sortOrder`，PRD §9 实体，另按项目惯例带 id/createdAt/updatedAt）；`from7To8` 迁移（createTable 幂等，仿 v7 里程碑）。
- **检查项 UI**：任务菜单「检查项…」打开 `ChecklistDialog`——顶部输入行 +「添加」；列表按 sortOrder 展示，每行 Checkbox（勾选划线，不只依赖颜色）+ 上移/下移 + 重命名 + 删除（二次确认）。
- **完成任务二次确认（FR-4.1 核心）**：`confirmCompleteTask` 共享函数——任务存在未完成检查项时弹「完成任务？」确认（「还有 N 个检查项未完成」），确认后完成、取消保持原状态；无未完成检查项时保持原行为。TaskTile（今天页/日历选日面板）与 `_TaskTile`（目标详情页/科目任务页）共用。
- **级联删除**：任务删除、JSON 替换导入删旧任务、目标级联删除时一并清理检查项（防孤儿数据，NFR-2）。
- **备份纳入（FR-9.1 全量业务数据）**：manifest 计数 `checklistItemCount`、`checklistItemToJson/FromJson`（taskId 外键映射）、导出 `data/checklist_items.json`、合并（旧→新任务 id 映射）、覆盖（保留原 ID、清空顺序 checklist_items 在 tasks 之前）、旧备份（无 checklist_items.json）兼容；诊断导出行数段新增 checklist_items。

## 3. 数据模型与迁移

ChecklistItem（PRD §9）：`taskId, title, done(bool), sortOrder`，加 id/createdAt/updatedAt 惯例字段；`done` 用 BoolColumn（仿 RecurrenceTemplates.active），非状态文本。

迁移 v7→v8（`lib/core/database/database.dart`）：

```dart
from7To8: (m, schema) async {
  // v7 -> v8：新增检查项表（FR-4.1 任务可包含可排序检查项）。
  // createTable 自带 IF NOT EXISTS，重复升级/半迁移安全。
  await m.createTable(schema.checklistItems);
},
```

- 全新安装：`onCreate: m.createAll()` 自动建全部表；
- 升级安装：`stepByStep` 增量建表；
- 幂等回归测试覆盖「表已手工创建但 user_version 落后」场景（半迁移）。
