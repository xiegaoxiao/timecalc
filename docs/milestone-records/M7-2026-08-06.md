# M7 里程碑验收记录（2026-08-06）：燃尽趋势 FR-7.3

## 1. 交付内容

- **燃尽趋势（FR-7.3）**：进度页新增燃尽趋势区（今日概览之后、热力图之前），展示最近 30 天「剩余预估时长」随日期的变化（实际线）+ 理想参考线（虚线）。
- **口径**：某日剩余 = 当前未完成时长和 + 窗口内完成日严格晚于该日的时长和——今日点 = 当前剩余（与 FR-7.1 口径一致）；随日期推进单调递减（完成日期越晚消化越晚）；无预估时长任务不计入（FR-7.4）。
- **理想参考线**：从窗口起点实际剩余起，按最晚进行中目标截止日线性递减到 0；endDate 不晚于窗口起点时参考线为 0。
- **图表（fl_chart 重构，迭代增强）**：fl_chart ^1.2.0 渲染——面积填充渐变、平滑曲线、实际线白描边节点、参考线虚线、浅色虚线网格、每 5 天日期轴、悬停 tooltip、入场生长动画；Header「当前剩余」大字 + 图例胶囊 + 卡片边框阴影；整体读屏语义（NFR-4）；空态提示。
- **统计层**：StatisticsService.burndownSeries 纯计算（无 schema 变更，无持久化状态，符合 checklists「统计由可验证查询产生」）。

## 3. 数据口径说明

燃尽窗口 = `[today-29 .. today]`（30 天，回顾式，与甘特图/热力图取向一致）。某日剩余含义为「该日时点仍欠着的工作量」：窗口内完成的任务在完成当天被「消化」，此前各日仍计欠账。today 点剩余恰等于 FR-7.1 的「目标剩余工作量」，两个口径在页面上一致。
