# M8 里程碑验收记录（2026-08-06）：每日自动备份 FR-9.4

## 1. 交付内容

- **每日自动备份（FR-9.4）**：设置页新增「自动备份」独立页——启用开关 + 两个目的地（本地目录 + WebDAV）；**应用运行期间语义**（桌面进程只在窗口/托盘存活时存在）：启动即检查一次 + `Timer.periodic(1h)` 复查，距上次成功不足 24 小时跳过（force 例外，「立即备份」按钮）；每个目的地只保留最近 7 份自动备份（FR-9.4 默认 7，前缀 `timecalc-auto-` 隔离，绝不删用户手动导出）。
- **WebDAV 目的地**：自研薄客户端（`http` 包提升为直接依赖，约 260 行）——MKCOL（405/301 视为已存在，幂等）/ PUT / PROPFIND（多命名空间前缀宽容解析，过滤目录项）/ GET / DELETE（404 幂等），Basic Auth；路径按段 percent-encode（非 ASCII 目录安全）；401 统一抛 `WebDavAuthException`；网络错误转可读文案。
- **凭据保护（NFR-3）**：WebDAV 密码经 `flutter_secure_storage`（Windows DPAPI）存系统凭据存储，key 以地址为维度；不落业务数据库、不进备份文件（FR-9.5）；设置页只存 `webdav_password_saved` 标记。
- **从备份位置恢复**：备份页新增「从备份位置恢复」——读取自动备份页配置，列出本地目录/WebDAV 的备份文件（来源标签 + 文件名 + 时间 + 大小，最新在前），选中后下载到临时文件，走原有「清单预览 + 合并/覆盖确认 + 覆盖前安全副本」全链路。
- **数据层（schema v9）**：Settings 表新增 6 列（`auto_backup_enabled`/`local_backup_folder`/`webdav_url`/`webdav_username`/`webdav_password_saved`/`last_auto_backup_at`），全部带默认值或可空，旧库免回填；`from8To9` 用 `addColumnIfMissing`（幂等，防半迁移）。
- **覆盖恢复保留运行时配置**：`BackupService._overwriteRestore` 连同 6 个自动备份配置列一起保留（与 close_behavior 同模式，FR-9.5 恢复语义：桌面/备份行为不被「数据恢复」意外改变）。

## 3. 数据模型与迁移

Settings（schema v9 新增 6 列，全部可空或带默认值）：

```dart
BoolColumn get autoBackupEnabled => boolean().withDefault(const Constant(false))();
TextColumn get localBackupFolder => text().nullable()();
TextColumn get webdavUrl => text().nullable()();
TextColumn get webdavUsername => text().nullable()();
BoolColumn get webdavPasswordSaved => boolean().withDefault(const Constant(false))();
DateTimeColumn get lastAutoBackupAt => dateTime().nullable()();
```

迁移 v8→v9（`lib/core/database/database.dart`）：`from8To9` 逐列 `addColumnIfMissing`（幂等，防半迁移重复），与 v5→v6 close_behavior 同模式。

- 全新安装：`onCreate: m.createAll()` 自动建全部列；
- 升级安装：`stepByStep` 增量补列；
- 幂等回归测试覆盖「列已手工补上但 user_version 落后」场景（半迁移）。

**覆盖恢复保留运行时配置**：备份 JSON 不含 6 个新列（FR-9.5），`_overwriteRestore` 删除 settings 行前读取当前值，恢复时回填（`settingsFromJson` 新增 6 个可选参数）。

## 4. 调度语义

- `AutoBackupScheduler`：`start()` 立即 `run()` 一次（启动补跑）+ 每小时复查；失败经 `onFailure` 弹 SnackBar（生产环境接 `DesktopController.scaffoldMessengerKey`，runApp 前未挂载时静默，下一小时复查继续）；同一自然日内同类失败只提示一次。
- `AutoBackupService.run({force})`：未启用 → 跳过；未配置目的地 → 跳过；距上次成功 <24h 且非 force → 跳过；否则导出 zip 到临时文件 → 逐目的地上传 + 剪枝 → **全部成功才推进 `last_auto_backup_at`**（失败不推进，避免静默跳过）。

## 9. 遗留事项

- Windows 计划任务唤醒式自动备份（应用完全关闭时也执行）未做——应用运行期间语义已满足 FR-9.4 主要场景，计划任务唤醒涉及任务注册/卸载与无界面错误反馈，留待后续评估。
- 自动备份文件未加密（zip 本体明文；凭据已加密）。WebDAV 走 HTTPS 时传输加密；如需端到端加密留待后续。
- WebDAV 服务器行为差异（部分实现不返回 PROPFIND 文件大小/时间、非标准错误码）已做宽容处理，未覆盖完整 RFC 4918 语义（如重定向跳转、分块上传大文件）。
- 手动导出文件名仍为 `timecalc-backup-<时间戳>`（非自动备份前缀，不被保留策略清理）。
