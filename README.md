# TimeCalc 时间计算器

TimeCalc 是一款本地优先的个人目标与截止日期管理工具，帮助用户把长期目标转换为今天可以执行的任务。

项目当前处于 Windows MVP 开发阶段，尚未发布正式版本。

## 产品方向

- 目标倒计时与里程碑
- 今日任务与日历排程
- 工作量和计划风险提示
- 重复任务与复习计划（含艾宾浩斯间隔序列）
- 本地数据存储与备份恢复
- 可选的 AI 计划草稿生成
- Windows 托盘与精简悬浮窗

完整需求和版本范围见 [产品需求文档](docs/requirements.md)。产品与工程参考见 [开源项目借鉴清单](docs/open-source-references.md)。

## 计划技术栈

- Flutter / Dart
- SQLite + drift
- Riverpod
- GoRouter

技术栈仍可能在首个工程里程碑开始前调整，产品验收以数据正确性和用户流程为准。

已完成（迭代增强）：

- JSON 导入任务（批量添加升级版）：科目与未分类隔离、自动校验（JSON 合法性/日期不得早于今天/非法日期拦截）、替换与合并两种导入模式。

- 重复任务（FR-4 模板 + 实例）：每天/每周指定星期/每隔 N 天/间隔序列（含艾宾浩斯 1,2,4,7,15,30），可扩展规则引擎（新增计划节奏只需注册 handler）。
- 时长显示人性化（分钟 →「N 小时 M 分」）与小时/分钟步进器输入。
- 代码审查修复（schema v5）：创建目标必选截止日期、科目删除不触发外键异常、任务备注可清空、重复任务编辑基础信息生效、逾期横幅不再被空态遮蔽、删除的重复实例不再复活（墓碑）等 P0/P1/P2 修复。
- 代码审查修复（M4 后）：时长步进长按失控与手势层失效、延期日期选择器越界、覆盖恢复保留关闭行为、备份恢复后详情/科目/重复任务页缓存陈旧、重复任务结束日期校验、批量添加间隔天数「所见≠所存」、间隔序列按绝对复习日解释、路由畸形参数重定向、窗口恢复尺寸下界钳制等 P0/P1/P2 修复（提交 `68df91e`，293 项测试全绿）。
- 进度页自适应布局重构：页面内容铺满窗口约 95%（消除宽屏左右留白）；今日概览三项等宽横向排布；热力图色块随卡片宽度动态放大铺满；甘特图按 flutter_gantt 布局重构（sticky 目标名列、月份 + ISO 周双刻度表头、网格线），周格宽等分铺满、行高随窗口高度与目标数自适应（不再绑定死高度），整页滚动查看全部行（295 项测试全绿）。
- 重复任务列表手风琴折叠（FR-4 迭代）：目标详情页/科目任务页中同一模板的多个实例合并为一张父卡片（标题 + 日期区间 + N 个任务），默认折叠，点击展开子任务列表（子任务保留复选框/日期/菜单，视觉内缩）；父卡片提供模板级菜单（编辑重复规则/停止重复/删除整个重复，删除二次确认提示实例数）；模板停止后标记「已停止」；单实例模板不折叠（326 项测试全绿）。

- 窗口位置/多屏恢复（FR-8.3）：保存窗口尺寸、位置、最大化状态与显示器信息；显示器不可用时回退主屏可见区域；窗口状态独立 JSON 存储，不进入业务备份（FR-9.5）。
