# TimeCalc 时间计算器

TimeCalc 是一款本地优先的个人目标与截止日期管理工具，帮助用户把长期目标转换为今天可以执行的任务。

项目当前处于 Windows MVP 开发阶段，尚未发布正式版本。

## 产品方向

- 目标倒计时与里程碑
- 今日任务与日历排程
- 工作量和计划风险提示
- 重复任务与复习计划（含艾宾浩斯间隔序列）
- 本地数据存储与备份恢复
- 可选的 AI 计划草稿生成
- Windows 托盘与精简悬浮窗

完整需求和版本范围见 [产品需求文档](docs/requirements.md)。产品与工程参考见 [开源项目借鉴清单](docs/open-source-references.md)。

## 计划技术栈

- Flutter / Dart
- SQLite + drift
- Riverpod
- GoRouter

技术栈仍可能在首个工程里程碑开始前调整，产品验收以数据正确性和用户流程为准。

## 项目状态

当前阶段：M1「数据与目标闭环」、M2「每日执行闭环」、M3「进度与数据保障」已完成，正在迭代增强与 M4「MVP 发布候选」规划之间。

已完成（M1）：

- Flutter Windows 工程与架构骨架（drift + Riverpod + GoRouter）。
- 目标、科目、任务的数据模型、数据库迁移与数据访问层。
- 目标 CRUD 与删除二次确认、今天页倒计时卡片、任务与科目 CRUD。
- 关键边界测试与 Windows 构建冒烟验证通过。

已完成（M2）：

- 今天页完整闭环：今日任务列表、完成/编辑/延期、快捷默认延期至下一可用日。
- 日历视图：月历负载、选日任务面板与历史日期补录。
- 今日负载「超出 X 分钟」提示、目标详情剩余工作量与计划风险提示。
- 次日未完成任务集中确认（FR-3.7）与设置页计划偏好（每日可用时长/每周可用日）。

已完成（迭代增强）：

- JSON 导入任务（批量添加升级版）：科目与未分类隔离、自动校验（JSON 合法性/日期不得早于今天/非法日期拦截）、替换与合并两种导入模式。
- 替换导入时旧任务归档保留到「历史任务」，可手动恢复。
- 重复任务（FR-4 模板 + 实例）：每天/每周指定星期/每隔 N 天/间隔序列（含艾宾浩斯 1,2,4,7,15,30），可扩展规则引擎（新增计划节奏只需注册 handler）。
- 时长显示人性化（分钟 →「N 小时 M 分」）与小时/分钟步进器输入。
- 代码审查修复（schema v5）：创建目标必选截止日期、科目删除不触发外键异常、任务备注可清空、重复任务编辑基础信息生效、逾期横幅不再被空态遮蔽、删除的重复实例不再复活（墓碑）等 P0/P1/P2 修复。

已完成（M3）：

- 进度统计与热力图：进度页今日概览（完成数/总数/已完成时长/目标剩余工作量）与最近 26 周完成热力图（LeetCode 官方配色，色块 tooltip + 图例文本，不只依赖颜色）；今天页负载卡同步展示 FR-7.1 统计行。
- 任务耗时甘特图：按目标分组的周时长图（过去 12 + 当前 + 未来 13 周窗口，能看到之后的任务计划），浅色为未来计划时长、深色为已完成时长，横向拖拽与悬停 tooltip。
- 手动备份/恢复：设置页「备份与恢复」区，导出带版本号的 `.timecalc` 备份（JSON 文件 + 配置目录 + zip 打包）；恢复前展示备份时间/目标数/任务数并要求确认「合并/覆盖」；覆盖恢复前自动创建当前数据安全副本（FR-9.3）；恢复先校验后原子生效，失败原库保持可用。
- 关闭行为设置（FR-8.1）：关闭按钮可配置为退出或最小化到托盘，首次触发时说明当前选择。
- 托盘（FR-8.2）：托盘图标 +「显示主窗口 / 退出」菜单。
- 窗口位置/多屏恢复（FR-8.3）：保存窗口尺寸、位置、最大化状态与显示器信息；显示器不可用时回退主屏可见区域；窗口状态独立 JSON 存储，不进入业务备份（FR-9.5）。
- 性能基线（NFR-1）：10,000 条任务数据下月历切换查询+聚合 13ms ≤ 500ms 基线测试。

下一里程碑（M4）：

1. 无障碍检查（键盘、非颜色状态、对比度、屏幕阅读器）。
2. P0 异常状态处理完整（含数据库异常提示从备份恢复或导出诊断）。
3. 安装包构建与发布资产（MSIX/安装包、版本号、变更日志、签名）。
